```text
|                                   |
|           Walimatul Urus          |

|                                   |
|               A & H               | <-- Monogram / Logo Pengantin
|                                   |
|                                   |
|          AISYAH & HAKIM           | <-- Tulisan Utama
|                                   |
|                                   |

|                                   |
|                                   |
|                                   |
|                                   |
| [*]                           [*] | <-- Corak Bucu Awan Larat (Emas)
+-----------------------------------+
```
